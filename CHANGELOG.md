# Change Log

## [0.1.1] - 2026-11-11

Initial Release 

### Added

- Overleaf-style inline comment threads for LaTeX, TeX and BibTeX files
- Tidy BibTeX File, by [bibtex-tidy](https://github.com/FlamingTempura/bibtex-tidy), with a diff preview.
- Update Entry Metadata looks up the entry at the cursor in arXiv, DBLP, Crossref and OpenAlex, and shows the result in the same diff preview.
- arXiv preprints are updated to their conference or journal version, including preprints published under a revised title.
- The merge keeps citation key, own fields and formatting style, and removes fields that no longer fit the entry type.
- Check Cited Papers for Retractions, using Crossref and the Retraction Watch database.
- Find Published Versions of Preprints for every arXiv-style entry in a `.bib` file at once.
- Reviews view
